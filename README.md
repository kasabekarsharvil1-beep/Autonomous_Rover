# Autonomous Military Surveillance Rover

## Project Overview
The Autonomous Military Surveillance Rover is a robotic vehicle designed for remote surveillance and monitoring in restricted or potentially dangerous areas.

The rover uses Raspberry Pi, sensors, a camera module, GPS, and IMU to detect obstacles, capture video, monitor movement, and provide location information.

## Objectives
- Develop an autonomous surveillance robot.
- Implement obstacle detection and avoidance.
- Capture images and live video using a camera.
- Monitor location using GPS.
- Monitor orientation and movement using IMU.
- Enable remote monitoring and control.

## Components Used
- Raspberry Pi
- Raspberry Pi Camera Module
- Ultrasonic Sensor
- IR Sensor
- GPS Module
- IMU Sensor
- L298N Motor Driver
- DC Gear Motors
- Battery
- Robot Chassis and Wheels

## Working Principle
1. Raspberry Pi acts as the main controller.
2. Sensors detect nearby obstacles.
3. Sensor data is processed by Raspberry Pi.
4. Motor driver controls the DC motors.
5. Camera captures the surrounding environment.
6. GPS provides location information.
7. IMU monitors orientation and movement.
8. Information can be transmitted for remote monitoring.
